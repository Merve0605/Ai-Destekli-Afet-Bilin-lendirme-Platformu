# Ai-Destekli-Afet-Bilin-lendirme-Platformu
Platform; yaşadığınız şehir ve ev koşullarına göre dinamik plan üretmenin yanı sıra enkaz altı ses duyurma düdüğü, interaktif afet çantası kontrol listesi, afet anı hareket rehberi ve acil durum hatlarına tek dokunuşla erişim gibi hayat kurtarıcı araçlar sunar.
